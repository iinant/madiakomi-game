# Медиакоми — «Угадай цену квартиры»

Мобильная игра по реальным объявлениям квартир республики Коми.
Сервис показывает фотографии квартиры, игрок передвигает бегунок и называет свою цену,
после чего видит реальную цену, разницу, баллы и ссылку на объявление. 10 раундов,
в конце — архетип игрока: **Жадный студент**, **Адекватный квартирант** или **Транжира**.

## Как играть

1. 10 случайных активных квартир из базы объявлений.
2. Галерея фотографий (свайп), бегунок цены, кнопка «Оценить».
3. Баллы за точность: до 5% — 10 б., до 10% — 8 б., до 20% — 6 б., до 30% — 4 б., до 50% — 2 б., больше — 0 б. Максимум — 100.
4. Архетип считается по суммарному перекосу оценок: оценки ниже реальных цен → «Жадный студент», в пределах ±3% → «Адекватный квартирант», выше → «Транжира».

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `madiakomi`).
2. Загрузите в него файлы: `index.html`, `data.js` (и `.nojekyll`).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/madiakomi/`.

Или через консоль:

```bash
git init
git add index.html data.js .nojekyll README.md
git commit -m "Медиакоми: игра «Угадай цену квартиры»"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/madiakomi.git
git push -u origin main
```

## Обновление данных

Исходная таблица: https://docs.google.com/spreadsheets/d/1YkdlO-y1hS9JZZowaNVz4mjCjS1KBNaMN6LdnxI9I2M/edit

```bash
curl -sL "https://docs.google.com/spreadsheets/d/1YkdlO-y1hS9JZZowaNVz4mjCjS1KBNaMN6LdnxI9I2M/gviz/tq?tqx=out:csv&gid=0" -o data_raw.csv
python build_data.py data_raw.csv data.js
```

Скрипт отбирает только активные объявления (есть ссылка и минимум 2 фото) и генерирует компактный `data.js`.

## Технические детали

- Один экран — одна карточка, мобильная версия в приоритете.
- Цвета в стиле hse.ru: `#012D6E`.
- Фотографии грузятся лениво (`loading="lazy"`) напрямую с CDN Авито.
- Без зависимостей и сборки — чистые HTML/CSS/JS, готово к GitHub Pages.
